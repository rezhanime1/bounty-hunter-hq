# Product — Bounty Hunter HQ

## Purpose

A single dashboard for a zero-capital crypto hunter. The hunter earns by
entering make.fun bounties, minting free BSC NFTs, and following a Telegram
alert bot. The app stitches those three incompatible sources into one view
so the hunter can decide what to do next in one glance.

## Users

One user: Rezhanime, a hunter with no capital chasing a $70 goal. Every
number on the dashboard must be honest — a `live` value fetched this
session, or a `cached` value with the time it was recorded. Nothing is
presented as live when it is not, and nothing promises a win.

## Features

1. Live make.fun bounty board (zero-capital only, soonest deadline first).
2. Free-mint radar on BSC with a live on-chain minted count for the
   featured mint (DUNE Keys) and recorded counts for the rest.
3. Earnings tracker: the hunter logs submissions; only `won` payouts count
   toward the $70 goal.
4. Telegram alerts panel linking to @AirdropHunterAIrez_bot.
5. Daily hunter checklist (news-image, race results, PXIO claim, FLOP
   faucet).

## Non-goals

- No wallet connection, no signing, no private keys, no transactions.
- No trading, no swaps, no paid mints, no entry fees.
- No server, no database, no accounts.
